# SCL-1.0-Open

Steven Compton Libraries — Open License v1.0  
(Permissive Open-Source License)

The **SCL-1.0-Open** license defines a permissive, open-source legal framework
designed for broad reuse while preserving clear attribution, identity
integrity, and protection against misleading representation.

The license permits unrestricted use, modification, redistribution, and
commercial deployment of software, while establishing firm boundaries around
authorship, branding, and behavioral claims.

This document outlines purpose, boundaries, and intended usage.

---

## Purpose

SCL-1.0-Open targets projects that seek open collaboration and wide adoption
without sacrificing clarity of origin or allowing confusing or deceptive
representation.

Projects select this license when they want:

- permissive open-source distribution  
- unrestricted commercial and private use  
- clear and discoverable authorship attribution  
- protection against brand or identity confusion  
- safeguards against misleading equivalence claims  
- compatibility with SPDX, SBOMs, and automated tooling  

The license emphasizes openness of use while preserving trust in provenance
and authorship.

---

## Core Concepts

### **Open Permission Model**

SCL-1.0-Open grants full permission to:

- use the Software  
- modify the Software  
- merge and extend the Software  
- redistribute the Software  
- sublicense the Software  
- sell products incorporating the Software  

No field-of-use restrictions apply.
No obligation exists to disclose modifications publicly.

---

### **Attribution and Origin Integrity**

All distributions preserve attribution to the Author.

Attribution must remain:

- accurate  
- reasonably discoverable  
- accessible through ordinary use  

Attribution communicates authorship only and never implies endorsement,
certification, or affiliation.

This ensures long-term clarity of origin even as the Software evolves through
forks and derivatives.

---

### **Identity and Representation Protection**

SCL-1.0-Open protects against:

- brand impersonation  
- misleading project naming  
- deceptive marketing or metadata  
- confusing claims of official status  
- unqualified behavioral equivalence  

Forks and derivatives remain free to innovate while adopting distinct naming
and branding that avoid confusion with the original Software.

Behavioral similarity claims require explicit qualification of non-affiliation
and independent authorship.

---

## Developer Expectations

Developers using this license:

- include the full license text with distributions  
- preserve original attribution  
- clearly mark modified versions  
- adopt distinct branding for forks or derivatives  
- avoid representations suggesting official status or endorsement  
- qualify any claims of behavioral similarity  

The license imposes no restrictions on innovation, competition, or
reimplementation, provided representation remains accurate and non-deceptive.

---

## SPDX Integration

**SPDX Identifier:** `SCL-1.0-Open`

Projects using this license include the identifier within:

- package manifests  
- SBOM files  
- SPDX documents  
- license scanners  
- compliance tooling  

This enables automated license detection and ecosystem compatibility.
